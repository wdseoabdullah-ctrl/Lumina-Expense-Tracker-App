# Lumina • Expense Tracker 💰

### A Beautiful & Modern Personal Expense Tracker

Welcome! This is a clean, elegant, and fully functional expense tracking application designed with a premium dark interface.  
Built to help you track daily expenses, visualize spending, and stay in control of your finances — all in a single file.

---

## 🚀 About This Project

- 💻 A modern single-page Expense Tracker built with pure HTML, CSS, and JavaScript.
- 🌱 Designed with a focus on clean UI/UX and smooth user experience.
- 🎯 Perfect for personal finance tracking without any backend or login.
- 🤖 Includes interactive charts and real-time calculations.
- 🔨 Built as a practical frontend project to practice modern web design.
- 🌍 Fully responsive and works offline.

---

## ✨ Features

- Beautiful dark theme with glassmorphism design
- Add, Edit, and Delete expenses
- Category-based tracking with colored icons
- Interactive doughnut chart (spending breakdown)
- Live summary cards (Total Spent, This Month, Transactions)
- Category filters
- LocalStorage support (data stays on your device)
- Export expenses as JSON
- Fully responsive design
- Smooth animations and toast notifications

---

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3 (Flexbox, Grid, Custom Properties, Backdrop Filter)
- Vanilla JavaScript

### Libraries
- Chart.js (for visual spending breakdown)

### Tools
- Google Fonts (Inter + Outfit)
- LocalStorage API

## 💻 How to Use

1. Download or clone the repository.
2. Open the `ExpenseTracker.html` file in any modern browser.
3. Start adding your expenses using the **+ Add Expense** button or the Quick Add form.
4. Your data will be automatically saved in the browser.

> No installation or server required — just open and use!
